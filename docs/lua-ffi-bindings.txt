Lua-FFI-Bindings 开发者参考手册
版本：1.0
适用环境：LuaJIT (Windows/Linux/macOS)

==============================================================================
1. 概览与初始化
==============================================================================

本库旨在提供跨平台的 C 语言标准库 (CRT) 和操作系统 API (SDK) 的 FFI 定义。其核心设计理念是通过 ffi.req 模块自动根据当前操作系统 (os) 和架构 (arch) 加载最合适的定义文件。

1.1 核心加载机制 (req.lua)
------------------------------------------------------------------------------
这是本库的入口点。请不要使用标准的 require 直接加载具体的路径（如 ffi.Windows.c.stdio），而应使用 ffi.req。

用法：
    local req = require 'ffi.req'
    req 'c.stdio'

搜索逻辑：
    加载器会按照以下顺序尝试查找模块：
    1. ffi.os.ffi.arch.模块名 (例如: ffi.Windows.x64.c.stdio)
    2. ffi.os.模块名 (例如: ffi.Windows.c.stdio)
    3. ffi.arch.模块名 (例如: ffi.x64.c.stdio)
    4. 模块名 (例如: ffi.c.stdio)

1.2 动态库加载器 (load.lua)
------------------------------------------------------------------------------
用于加载动态链接库（.dll, .so, .dylib）。它比标准的 ffi.load 更智能，支持平台特定的库名称重映射和环境变量扩展。

用法：
    local ffi_load = require 'ffi.load'
    local lib = ffi_load '库标识符'

特性：
    - 自动识别操作系统并加载对应的库文件（例如在 Windows 加载 OpenGL32，在 macOS 加载 OpenGL.framework）。
    - 支持路径中的环境变量扩展（如 %SystemRoot% 或 $HOME）。
    - 预设支持：kernel32, user32, shell32, advapi32, ntdll, psapi, GL, GLU, openal, z (zlib) 等。
    - 如果未在预设表中找到，将直接作为库名称传递给 ffi.load。

==============================================================================
2. C 标准运行时库 (CRT) 模块
==============================================================================

所有 CRT 模块均通过 req 'c.模块名' 加载。在 Windows 上，这些绑定主要指向 UCRT (Universal CRT)。

注意：Windows 版本的绑定主要使用宽字符 (UTF-16/wchar_t) 版本的 API。

2.1 输入输出 (c.stdio / c.corecrt_wstdio)
------------------------------------------------------------------------------
提供标准输入输出功能。

主要结构体：
    FILE (不透明指针)

主要函数：
    fopen / _wfopen(文件路径, 模式) - 打开文件（推荐使用 _wfopen 以支持中文路径）
    fclose(stream) - 关闭文件
    fread(buffer, size, count, stream) - 读取数据
    fwrite(buffer, size, count, stream) - 写入数据
    fseek(stream, offset, origin) - 定位流
    ftell(stream) - 获取当前位置
    fflush(stream) - 刷新缓冲区
    printf / wprintf - 格式化输出到标准输出
    fprintf / fwprintf - 格式化输出到流
    sprintf / swprintf / snprintf - 格式化输出到缓冲区
    vfprintf / vprintf 等 -以此类推的变参版本
    remove / _wremove - 删除文件
    rename / _wrename - 重命名文件

2.2 字符串操作 (c.string / c.corecrt_wstring)
------------------------------------------------------------------------------
提供内存块和字符串处理功能。

主要函数 (ANSI / Wide 对应版本)：
    memcpy - 内存复制
    memset - 内存设置
    memcmp - 内存比较
    memmove - 内存移动
    strlen / wcslen - 获取字符串长度
    strcpy / wcscpy - 字符串复制
    strcat / wcscat - 字符串拼接
    strcmp / wcscmp - 字符串比较
    strchr / wcschr - 查找字符
    strstr / wcsstr - 查找子串
    _strdup / _wcsdup - 复制字符串（需手动 free）

2.3 内存与环境 (c.stdlib / c.corecrt_wstdlib)
------------------------------------------------------------------------------
提供内存分配、数值转换和环境控制。

主要函数：
    malloc(size) - 分配内存
    calloc(count, size) - 分配并清零
    realloc(ptr, size) - 重新分配
    free(ptr) - 释放内存
    exit(code) / abort() - 终止程序
    system / _wsystem(cmd) - 执行系统命令
    getenv / _wgetenv(varname) - 获取环境变量
    _putenv / _wputenv(envstring) - 设置环境变量
    atoi / _wtoi, atof / _wtof - 字符串转数值
    strtod / wcstod, strtol / wcstol - 字符串转数值（带尾指针）
    qsort - 快速排序
    bsearch - 二分查找
    rand / srand - 随机数

2.4 时间与日期 (c.time / c.corecrt_wtime)
------------------------------------------------------------------------------
处理系统时间。自动处理 32位/64位 时间类型差异。

主要结构体：
    struct tm { tm_sec, tm_min, tm_hour, tm_mday, tm_mon, tm_year, ... }
    struct timespec { tv_sec, tv_nsec }

主要函数：
    time(timer) - 获取当前时间戳
    clock() - 获取处理器时间
    difftime(end, begin) - 计算时间差
    mktime(tm) - struct tm 转时间戳
    gmtime(timer) - 时间戳转 UTC struct tm
    localtime(timer) - 时间戳转本地 struct tm
    strftime / wcsftime - 格式化时间字符串
    _wctime - 时间戳转宽字符串

2.5 文件状态与目录 (c.sys.stat / c.direct)
------------------------------------------------------------------------------
获取文件属性及操作目录。

主要结构体：
    struct stat (Windows 下映射为 struct _stat64)
        字段: st_dev, st_ino, st_mode, st_nlink, st_uid, st_gid, st_rdev, st_size, st_atime, st_mtime, st_ctime

主要函数：
    stat(path, buf) / _wstat64(path, buf) - 获取文件状态
    fstat(fd, buf) / _fstat64(fd, buf) - 获取已打开文件的状态
    _getcwd / _wgetcwd - 获取当前工作目录
    _chdir / _wchdir - 改变当前工作目录
    _mkdir / _wmkdir - 创建目录
    _rmdir / _wrmdir - 删除目录

2.6 错误处理 (c.errno)
------------------------------------------------------------------------------
此模块返回一个对象而非直接的 C 定义。

用法：
    local errno = require 'ffi.req' 'c.errno'
    local err_code = errno.errno()  -- 获取当前的 errno 数值
    local err_msg = errno.str()     -- 获取当前的错误描述字符串

2.7 其他 CRT 模块
------------------------------------------------------------------------------
c.io: 提供底层的 _open, _read, _write, _close, _lseeki64 等 POSIX 风格 IO。
c.fcntl: 定义了文件锁结构 struct flock 及相关常量。
c.utime: 提供 _utime32/_utime64 用于修改文件时间戳。
c.process: 提供 _execl, _spawnl, _getpid 等进程控制函数。
c.limits: 定义了 INT_MAX, LLONG_MAX 等数值极限常量。
c.stdint: 定义了 int32_t, uint64_t 等定长整数类型。

==============================================================================
3. Windows SDK 模块
==============================================================================

位于 Windows.sdk.* 命名空间下。
重要提示：SDK 绑定中的字符串参数几乎全部定义为 LPCWSTR (const wchar_t*)。在调用时请确保传递宽字符（UTF-16）数据。

3.1 基础定义 (Windows.sdk.minwindef)
------------------------------------------------------------------------------
定义了 Win32 API 的核心类型。

类型：
    BOOL (int), BYTE (unsigned char), WORD (unsigned short), DWORD (unsigned long)
    HANDLE, HWND, HMODULE, HINSTANCE (void*)
    LPCWSTR (const wchar_t*), LPWSTR (wchar_t*)
    WPARAM (UINT_PTR), LPARAM (LONG_PTR), LRESULT (LONG_PTR)

3.2 核心内核 (Windows.sdk.kernel32)
------------------------------------------------------------------------------
覆盖文件、进程、线程、内存、动态库等核心功能。

文件操作：
    CreateFileW - 创建或打开文件/设备
    CopyFileW - 复制文件
    MoveFileExW - 移动或重命名文件
    DeleteFileW (需确认源码，通常存在于 Kernel32)
    CreateHardLinkW / CreateSymbolicLinkW - 创建链接
    GetTempPathW / GetTempFileNameW - 获取临时路径

进程与线程：
    CreateProcessW - 创建新进程
    OpenProcess - 获取进程句柄
    TerminateProcess - 终止进程
    WaitForSingleObject - 等待句柄信号
    GetCurrentProcessId / GetProcessId - 获取 PID
    Sleep - 线程休眠
    GetModuleFileNameW - 获取模块路径
    LoadLibraryW / FreeLibrary - 加载/卸载 DLL

系统工具：
    GetLastError / SetLastError - 错误码管理
    FormatMessageW - 格式化错误消息
    GetTickCount / GetTickCount64 - 系统运行时间
    SetEnvironmentVariableW / GetEnvironmentVariableW - 环境变量
    WideCharToMultiByte / MultiByteToWideChar - 编码转换

3.3 用户界面 (Windows.sdk.user32)
------------------------------------------------------------------------------
提供窗口管理和消息机制。

主要函数：
    MessageBoxA - 弹出消息框 (注意：源码中仅定义了 A 版)
    PostQuitMessage - 发送退出请求
    PeekMessageW / TranslateMessage / DispatchMessageW - 消息循环处理
    MsgWaitForMultipleObjects - 等待对象或消息
    EnumWindows - 枚举顶层窗口
    GetWindowThreadProcessId - 获取窗口对应的线程和进程ID
    IsWindowVisible - 判断窗口可见性
    PostMessageW - 投递消息

3.4 外壳工具 (Windows.sdk.shell32)
------------------------------------------------------------------------------
不仅包含 FFI 定义，还提供了 Lua 辅助函数。

原始 API：
    CommandLineToArgvW - 解析命令行字符串
    GetCommandLineW - 获取原始命令行

Lua 封装接口 (直接在 require 返回的表中使用)：
    shell.commandline_to_argv(cmd_line_str)
        输入：UTF-8 字符串
        输出：参数表 (table) 或 nil, error
        功能：自动进行 UTF-8 到 WideChar 的转换、调用 API 解析、释放内存并转换回 UTF-8 表。

    shell.get_arguments()
        输出：参数表 (table)
        功能：获取当前进程的命令行参数并解析为 Lua 表。

3.5 高级安全 (Windows.sdk.advapi32)
------------------------------------------------------------------------------
涉及注册表、服务和访问令牌。

主要函数：
    OpenProcessToken - 打开进程令牌
    DuplicateTokenEx - 复制令牌
    AdjustTokenPrivileges - 调整令牌权限
    LookupPrivilegeValueW - 查找权限 LUID
    CreateProcessAsUserW - 以特定用户身份启动进程

3.6 其他 SDK 模块
------------------------------------------------------------------------------
Windows.sdk.ntdll:
    NtQueryInformationProcess - 查询底层进程信息 (PEB, 命令行等)

Windows.sdk.psapi:
    GetModuleFileNameExW - 获取指定进程的模块文件名
    GetProcessMemoryInfo - 获取进程内存使用统计

Windows.sdk.wtsapi32:
    WTSQueryUserToken - 获取会话用户令牌

Windows.sdk.userenv:
    CreateEnvironmentBlock / DestroyEnvironmentBlock - 创建/销毁环境块

==============================================================================
4. Lua C API 绑定 (Windows.lua)
==============================================================================

提供 Lua 5.3+ 风格的 C API 定义，允许通过 FFI 直接操作 Lua 状态机。

主要类型：
    lua_State, lua_KContext, lua_CFunction

主要函数：
    lua_gettop / lua_settop - 栈管理
    lua_pushvalue / lua_copy / lua_rotate - 栈操作
    lua_isnumber / lua_isstring / lua_isuserdata - 类型检查
    lua_tonumberx / lua_tointegerx / lua_tostring - 值获取
    lua_pushnumber / lua_pushinteger / lua_pushstring - 值压栈
    lua_getglobal / lua_setglobal - 全局变量操作
    lua_gettable / lua_settable / lua_getfield - 表操作
    lua_pcallk / lua_callk - 函数调用
    luaL_loadfilex / luaL_loadstring - 代码加载
    luaL_newstate / luaL_openlibs - 状态机创建

==============================================================================
5. 快速上手示例
==============================================================================

示例：调用 Windows Kernel32 API 获取当前路径
------------------------------------------------------------------------------
local ffi = require 'ffi'
local req = require 'ffi.req'
local kernel32 = require 'ffi.load' 'kernel32' -- 加载 DLL
req 'Windows.sdk.kernel32'                     -- 加载函数定义

-- 定义缓冲区大小
local MAX_PATH = 260
local buffer = ffi.new("wchar_t[?]", MAX_PATH)

-- 调用 GetModuleFileNameW (传入 NULL 获取当前进程路径)
local len = kernel32.GetModuleFileNameW(nil, buffer, MAX_PATH)

if len > 0 then
    -- 注意：需要将 wchar_t* 转换为 Lua 字符串
    -- 这里为了简便，仅演示调用成功，实际转换需使用 WideCharToMultiByte
    print("Success! Path length: " .. len)
end

示例：使用 CRT 进行文件写入
------------------------------------------------------------------------------
local ffi = require 'ffi'
local req = require 'ffi.req'
req 'c.stdio' -- 加载 stdio 定义

local filename = "test.txt"
local mode = "w"
local file = ffi.C.fopen(filename, mode)

if file ~= nil then
    local text = "Hello from Lua FFI"
    ffi.C.fprintf(file, "%s\n", text)
    ffi.C.fclose(file)
    print("File written.")
else
    print("Failed to open file.")
end
